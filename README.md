# 3D Neglecting Game

3D 방치형 액션 RPG 프로토타입 (Unity, 2023~2024). 캐릭터가 스테이지를 자동으로 진행하며 싸우고, 플레이어는 성장 요소를 관리한다.

- 플레이어 · 적 모두 행동 트리(BT) AI로 자동 전투
- 스킬: 연속 공격 · 자가 회복 등, 스킬 레벨업
- 레벨업 능력치: 체력 · 이동 속도 · 공격 속도 · 공격력
- 장비 슬롯: 무기 · 방어구 · 장신구, 인벤토리
- 상점: 재화 · 스킬 · 아이템 구매. 재화는 골드 · 다이아 · 루비 · 에메랄드 · 경험치
- 진행 데이터 저장 · 불러오기
